# Voice — Virtina

This file defines how the creator agent writes for this client. The voice file overrides general writing best practices when they conflict.

## Tone

- Professional but approachable — knowledgeable, not jargon-heavy
- Confident without being salesy
- Slightly conversational: like talking to a smart colleague
- Written for ecommerce brands; assume the reader knows their business

## Person

- Second person ("you") when addressing the reader
- Contractions are fine: "don't", "you're", "it's"
- No slang

## Sentence and paragraph rules

- Short paragraphs: 2–3 sentences max for online reading
- Active voice throughout
- Lead with the strongest sentence in each section
- One idea per paragraph

## Punctuation

- Em dashes: allowed, use sparingly
- Semicolons: never
- Oxford comma: yes
- Exclamation marks: never

## Headings

- Sentence case, not Title Case

## Banned words and phrases

AI tells (never use):
- delve, leverage, synergy, navigate (as a verb), realm, landscape, ecosystem
- "in today's fast-paced world"
- "it's important to note"
- "in conclusion"
- "in the world of"

Hype words (never use):
- revolutionary, game-changing, cutting-edge, best-in-class
- "transform your..."

## Formatting

- Bold: for emphasis only, never for whole sentences
- Bullet lists: only when items are genuinely parallel
- No emoji unless the brand file explicitly allows

## Citations

- Inline Markdown links to primary sources
- Never link to aggregators when the original is reachable
- Date the claim if it's time-sensitive
