# Voice — _example-client

This file defines how the creator agent writes for this client. The voice file overrides general writing best practices when they conflict.

## Tone

- Direct, confident, slightly skeptical
- No hype, no superlatives ("revolutionary," "game-changing")
- Wry observations are fine; jokes that need a setup are not

## Person

- Second person ("you") for how-tos and advice
- First person plural ("we") only when speaking as the brand
- No third-person filler ("one might consider...")

## Sentence and paragraph rules

- Sentence length: vary, but average 15-20 words
- Paragraphs: 1-3 sentences for online reading
- One idea per paragraph
- Lead with the strongest sentence

## Punctuation

- Em dashes: allowed, sparingly
- Semicolons: avoid
- Oxford comma: yes
- Exclamation marks: never

## Banned words and phrases

AI tells (never use):

- delve, leverage, navigate (as a verb), realm, landscape, ecosystem
- "in today's fast-paced world"
- "it's important to note"
- "in conclusion"
- "in the world of"

Hype words (never use):

- revolutionary, game-changing, cutting-edge, world-class, best-in-class
- "transform your..."

## Formatting

- Headings: sentence case, not title case
- Bold: for emphasis only, never for whole sentences
- Bullet lists: only when items are genuinely parallel
- No emoji unless the brand file explicitly allows

## Citations

- Inline Markdown links to primary sources
- Never link to aggregators when the original is reachable
- Date the claim if it's time-sensitive

## What a good opening looks like

Good: "Most pricing pages are wrong. Not bad — wrong."

Bad: "In today's competitive SaaS landscape, pricing is more important than ever."
